# Myrmex — музыкальная процедурная анимация персонажей из Hunyuan3D

**Hunyuan3D GLB → доводка в Blender → авто-риг любой морфологии → поведенческий движок,
управляемый музыкой (Ableton / VCV Rack / стемы) → запекание и кинематографичный рендер.**

Статус: в разработке. Работает (проверено на реальном ассете Hunyuan3D):

- импорт и нормализация ассета, ремонт сетки, ретопология QuadriFlow;
- автоматический морфологический анализ (дерево слияния геодезических расстояний)
  и авто-риг гуманоида + геодезические веса + Corrective Smooth;
- процедурный мотор двуногих: стопы без скольжения, перекат пятка→носок,
  таз-маятник, противовращение корпуса, маятниковые руки с защитой от проникания;
- музыкальный слой: признаки, память, структура (интро/билд/дроп/брейк…),
  предиктор грува (предвосхищение, удивление, пропуск удара, вход инструмента);
- поведенческий движок: драйвы, стратегии, 16 поведений, реакции с привыканием,
  мягкий захват бита, конфигурируемые маппинги (JSON);
- генерация исполнения, запекание в Blender 4.2–5.2 LTS, превью-рендер со звуком.
